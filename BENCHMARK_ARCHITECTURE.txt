DATA FLOW
---------

1. Dataset Creation
   User Audio Files → Dataset Manager → metadata.json

2. Benchmark Execution
   Dataset → Provider → Transcription → Metrics Calculation
                   ↓
          Resource Monitor (GPU/CPU/RAM)
                   ↓
          Cost Estimator ($/min)
                   ↓
          Benchmark Runner (orchestrate)
                   ↓
          Results Storage (SQLite)

3. Report Generation
   Results → Report Generator → HTML/MD/CSV/JSON

4. Historical Analysis
   SQLite DB → Query Interface → Comparisons/Trends

PROVIDER INTERFACE
------------------

STTProvider (Abstract Base)
├── initialize() → bool
├── transcribe(audio_path) → TranscriptionResult
├── transcribe_stream(audio_data) → TranscriptionResult
├── cleanup() → None
├── get_cost_per_minute() → float
└── supports_language(lang) → bool

TranscriptionResult
├── text: str
├── confidence: float
├── language: str
├── processing_time_ms: float
├── audio_duration_ms: float
├── segments: List[Dict]
└── rtfx: float (computed property)

BenchmarkMetrics
├── Accuracy: wer, cer, avg_confidence
├── Performance: rtfx, latency_p50/95/99, throughput
├── Resources: gpu_memory_mb, cpu_percent, ram_mb
├── Cost: cost_per_minute, cost_per_hour
├── Metadata: sample_count, test_timestamp, hardware
└── get_score() → float (0-10)

SCORING ALGORITHM
-----------------

Overall Score = (Accuracy × 0.4) + (Speed × 0.3) + (Cost × 0.3)

Accuracy Score (0-10):
  WER ≤ 5%  → 10.0
  WER ≤ 10% → 8.0-10.0 (linear)
  WER ≤ 20% → 5.0-8.0 (linear)
  WER > 20% → 0.0-5.0 (linear)

Speed Score (0-10):
  Latency < 100ms & RTFx < 0.1 → 10.0 (real-time)
  RTFx < 0.5 → 8.0-10.0 (fast batch)
  RTFx < 1.0 → 5.0-8.0 (moderate)
  RTFx > 1.0 → 0.0-5.0 (slow)

Cost Score (0-10):
  FREE → 10.0
  < $0.10/hr → 9.0
  < $0.50/hr → 7.0
  < $1.00/hr → 5.0
  > $1.00/hr → 0.0-3.0

--------------

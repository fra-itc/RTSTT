# 📘 Frisco Whisper RTX - Brand Guidelines

Complete brand identity and visual guidelines for Frisco Whisper RTX.

## 🎯 Brand Identity

### Mission Statement

"Empowering professionals with GPU-accelerated speech recognition technology that delivers unmatched speed, accuracy, and reliability."

### Brand Attributes

- **High-Performance**: RTX acceleration for instant results
- **Professional**: Enterprise-grade quality and reliability
- **Cutting-Edge**: Latest AI/ML technology
- **Accessible**: Powerful yet intuitive interface

### Target Audience

- **Primary**: Content creators, developers, researchers
- **Secondary**: Enterprises, medical professionals, legal firms
- **Technical Level**: Advanced users comfortable with GPU technology


❌ Don't change logo colors (except approved variants)
❌ Don't add effects (drop shadows, outlines) beyond approved glow
❌ Don't place on busy backgrounds without clear space
❌ Don't rotate the logo

### Typography

#### Font Hierarchy

**Display Font: Orbitron**
- **Use**: Page titles, section headers, logo
- **Weights**: Bold (700), Black (900)
- **Character**: Tech-forward, gaming aesthetic
- **Letter Spacing**: +0.05em to +0.1em

**Body Font: Inter**
- **Use**: UI text, descriptions, body content
- **Weights**: Regular (400), Medium (500), Semibold (600), Bold (700)
- **Character**: Clean, modern, highly readable
- **Line Height**: 1.5 (normal), 1.75 (relaxed)

**Monospace Font: JetBrains Mono**
- **Use**: Code, logs, file paths, technical data
- **Weights**: Regular (400), Medium (500), Bold (700)
- **Character**: Developer-friendly, ligature support
- **Line Height**: 1.5

#### Type Scale

```
Hero Text     48px  3rem    font-display  Black    Tight (1.25)
Page Header   32px  2rem    font-display  Bold     Tight (1.25)
Section       24px  1.5rem  font-display  Bold     Tight (1.25)
Subheading    20px  1.25rem font-primary  Semibold Normal (1.5)
Large Body    18px  1.125rem font-primary Medium   Normal (1.5)
Body          16px  1rem    font-primary  Regular  Normal (1.5)
Small         14px  0.875rem font-primary Regular  Normal (1.5)
Caption       12px  0.75rem  font-primary Regular  Normal (1.5)
```

#### Typography Best Practices

✅ **Do:**
- Use Orbitron for impact and branding
- Use Inter for readability and clarity
- Use JetBrains Mono for technical accuracy
- Maintain consistent hierarchy
- Test with real content

❌ **Don't:**
- Mix more than 3 font families
- Use Orbitron for body text (poor readability)
- Use decorative fonts for accessibility
- Reduce below minimum sizes

## 🎭 Voice & Tone

### Brand Voice

**Tech-Forward Professional**
- Precise, accurate language
- Technical but accessible
- Confident without arrogance
- Educational when helpful

### Tone Variations

**Marketing/Landing Pages**
- Energetic, exciting
- Feature-focused
- Performance-oriented
- "Experience RTX-accelerated transcription"

**UI/Application**
- Concise, informative
- Action-oriented
- Status-clear
- "Processing audio with large-v3 model..."

**Documentation**
- Clear, structured
- Step-by-step
- Code examples
- "Configure your GPU settings in 3 steps"

**Error Messages**
- Helpful, solution-oriented
- Never blame the user
- Provide actionable steps
- "GPU not detected. Check CUDA installation."

### Writing Guidelines

**Do:**
- Use active voice
- Be specific with numbers
- Explain technical terms
- Provide examples

**Don't:**
- Use jargon without explanation
- Write overly casual
- Make assumptions about knowledge
- Use passive voice

### Examples

**Good:**
> "Transcribe 1 hour of audio in under 5 minutes with RTX 5080 acceleration."

**Bad:**
> "It's really fast and stuff works great!"

**Good:**
> "Model loaded: Whisper large-v3 (3.09 GB VRAM)"

**Bad:**
> "Big model is ready now"

## 🎬 Motion & Animation

### Principles

1. **Purposeful**: Animations serve a function
2. **Smooth**: 60fps target, GPU-accelerated
3. **Subtle**: Enhance, don't distract
4. **Fast**: 150-350ms duration
5. **Responsive**: Immediate feedback

### Animation Types

**Micro-interactions**
- Button hover: 150ms
- Card hover: 250ms
- Modal open: 300ms
- Page transition: 350ms

**Status Indicators**
- Pulse: 2s infinite (processing)
- Glow: 2s infinite (active)
- Scan line: 4s infinite (analyzing)
- Spin: 1s infinite (loading)

**Entrance/Exit**
- Fade in: 300ms ease-out
- Slide up: 300ms ease-out
- Scale in: 250ms ease-smooth
- Fade out: 200ms ease-in

### Easing Functions

```javascript
const easings = {
  smooth: 'cubic-bezier(0.4, 0, 0.2, 1)', // Default
  linear: 'linear',                        // Constant speed

  easeOut: 'cubic-bezier(0, 0, 0.58, 1)', // Decelerate

```

**Desktop (≥1024px)**
- 12-column grid
- Gutter: 24px

- Margins: 48px

**Tablet (768-1023px)**
- 8-column grid
- Gutter: 16px
- Margins: 32px

**Mobile (<768px)**
- 4-column grid
- Gutter: 16px
- Margins: 16px

### Spacing Scale

```
Based on 4px (0.25rem) unit:

 4px  = 1 unit  = space-1
 8px  = 2 units = space-2
12px  = 3 units = space-3
16px  = 4 units = space-4  ⭐ BASE
24px  = 6 units = space-6
32px  = 8 units = space-8
48px  = 12 units = space-12
64px  = 16 units = space-16
```

**Inputs**

## 📱 Platform-Specific Guidelines

### Web Application

- Use glassmorphism sparingly
- Ensure 60fps animations
- Test on multiple browsers
- Support dark mode by default

### Desktop Application (Electron)

- Native window controls
- System tray integration
- OS-specific shortcuts
- Hardware acceleration enabled

### Mobile (Future)

- Touch-friendly targets (44px minimum)
- Simplified navigation
- Reduce glow effects (battery)
- Optimize for small screens
